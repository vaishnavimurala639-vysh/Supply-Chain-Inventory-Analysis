# Supply Chain Inventory Analysis

## Project Overview
This project analyzes supply chain inventory data using Microsoft Excel to understand sales, revenue, profit, inventory levels, and shipping performance.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas

## Key Analysis
- Total Revenue
- Total Profit
- Total Units Sold
- Total Stock
- Average Shipping Time
- Inventory Status Analysis
- Top Selling Products

## Dashboard
The Excel dashboard provides a visual summary of key business metrics and inventory performance.
